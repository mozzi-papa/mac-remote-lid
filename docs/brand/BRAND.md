# 원격지킴이 브랜드 정체성

상태: A안 선택 · 웹 적용 기준 · 2026-11-03

## 브랜드 역할

원격 작업에 쓰는 Mac의 잠자기를 관리하고, 작업을 마치면 앱이 변경한 전원 설정을 이전 값으로 복원하는 작은 메뉴 막대 도구입니다.

브랜드명은 **원격지킴이**, 보조 영문명은 **RemoteLid**를 유지합니다. 새 이름이나 기능을 만드는 리브랜딩이 아니라, 현재 기능을 더 정확하게 전달하는 시각 정리입니다.

## 누구를 위한 도구인가요

Apple Silicon Mac을 켜 두고 다른 기기에서 접속하거나, 자리를 비운 동안 작업을 이어가려는 사용자를 대상으로 합니다. 다운로드 페이지에서는 기능, 지원 환경, 설정 복원 방식과 설치 방법을 빠르게 이해할 수 있어야 합니다.

사용자가 기술 전문가라는 가정은 하지 않습니다. 터미널 명령 없이도 ZIP 다운로드와 앱 메뉴로 주요 흐름을 이해할 수 있게 안내합니다.

## 핵심 약속

**필요한 동안 깨어 있게. 마치면 이전 설정으로.**

이 약속은 켜짐 상태와 복원 동작을 설명합니다. 연결 안정성이나 무중단 운영을 보장하는 문구가 아닙니다.

## 브랜드 성격

- 조용함: 켜짐을 과장하지 않고 현재 상태를 보여줍니다.
- 명확함: 적용한 설정, 복원할 설정, 확인할 수 없는 상태를 구분합니다.
- 통제 가능함: 위험을 안내하고 유지 여부는 사용자가 선택합니다.

디자인의 차별점은 장식용 '보호' 상징보다 **상태와 되돌림의 짝**에 둡니다. 로고도 이 관계를 작은 크기에서 보여줄 수 있는지 평가합니다.

## 제품 사실과 표현의 경계

| 설명할 사실 | 피할 표현 |
| --- | --- |
| 잠자기 방지와 전원 설정 복원 | 24시간 무조건 연결, 완벽한 원격 접속 |
| 화면 꺼짐 방해 앱의 요청 조회 | 다른 앱 요청을 자동 해제, 화면 강제 끄기 |
| 배터리 위험 경고 후 사용자 선택 | 배터리가 부족하면 자동으로 안전 종료 |
| macOS가 관리자 인증 처리 | 원격 접속 보안·암호화·백신 기능 제공 |
| 개인용 로컬 서명 빌드 | Apple 인증·공증 완료 |

원격 접속 자체는 사용자가 다른 프로그램에서 구성합니다. 덮개를 닫은 장시간 연결, 정전·재시동 방지는 보장하지 않습니다. 최신 버전과 지원 환경은 배포 시 실제 앱 정보를 기준으로 갱신합니다.

## 문구와 말투

화면 문구와 문서는 존댓말로 작성합니다. 짧은 동사와 사용자가 보는 상태를 사용합니다. '혁신적인', '완벽한', '압도적인'처럼 근거 없는 수식어를 쓰지 않습니다.

- 주요 설명: “Mac의 잠자기를 막고, 마치면 이전 설정으로 돌아갑니다.”
- 주요 행동: “Mac용 다운로드”, “설치 방법 보기”
- 켜짐: “원격 모드가 켜져 있습니다.”
- 복원 실패: “이전 설정 복원을 확인하지 못했습니다. 복원 기록을 유지했습니다.”
- 배터리 안내: “전원 상태를 확인하고 유지 여부를 선택해 주세요.”

## 로고 선택 확정

2026-11-03 사용자가 A안을 선택했습니다. 첨부한 Mac 메뉴 막대 아이콘의 화면 윤곽과 상태점을 브랜드 연속성의 근거로 삼습니다. 웹사이트에는 화면 윤곽·중앙 초록 점·하단 받침선으로 구성한 수정 A안을 사용합니다. 로고의 중앙 초록 점은 브랜드 표식이며 실제 앱의 현재 상태를 뜻하지 않습니다. 기존 네이티브 앱 아이콘은 변경하지 않습니다.
