# 원격지킴이 시각 정체성

상태: A안 선택 · 웹 적용 기준 · 2026-11-03
관련 문서: [브랜드 정체성](BRAND.md), [브랜드 보드](preview.html)

## 시각 방향

**Mac 곁에 두는 작은 도구.** 알루미늄 하드웨어와 시스템 창에 어울리는 중립 표면을 사용합니다. 현재 페이지의 제품 이미지와 설명 구조는 활용하되, 청록 배경과 민트 조명으로 화면 전체를 물들이는 방식은 정리합니다.

흑연색 글자와 실버 표면으로 정보의 위계를 만들고, 초록은 '켜짐'처럼 실제 상태를 전달하는 데 사용합니다. 짙은 배경은 로고 반전이나 화면 비교에 사용하며 랜딩페이지 전체를 어둡게 바꾸지 않습니다.

## 색상 토큰

| 토큰 | 값 | 사용 |
| --- | --- | --- |
| canvas | #FCFCFD | 기본 배경 |
| graphite | #202124 | 본문·제목·주요 다운로드 버튼 |
| secondary | #565B63 | 설명·보조 정보 |
| silver | #ECEEF1 | 제품 이미지 주변 표면·예시 배경 |
| line | #D9DDE1 | 비상호작용 영역 구분선 |
| active | #237A4B | 작동 상태·켜진 스위치 |

기본 배경의 본문과 보조 글자는 WCAG AA 일반 본문 대비 4.5:1 이상을 기준으로 합니다. line은 글자나 컨트롤 상태를 구분하는 유일한 수단으로 사용하지 않습니다. 포커스는 graphite 2픽셀 외곽선과 4픽셀 간격으로 표시합니다. 오류·주의는 기존 시스템 의미를 유지하고 텍스트로 설명합니다.

초록으로 제목 일부를 칠하거나 장식용 점을 붙이지 않습니다. 청록·민트·보라 그라데이션, 배경 발광과 장식용 유리 효과는 사용하지 않습니다.

## 타이포그래피

네이티브 도구와의 연결을 위해 로컬 시스템 산세리프를 사용합니다. 외부 폰트를 요청하지 않습니다.

- 한글 본문·제품 설명: Apple SD Gothic Neo, 시스템 sans-serif. 16픽셀, 줄높이 1.75.
- 제목: 같은 계열, 굵기 650~700. 첫 제목 최대 64픽셀, 모바일 38~44픽셀. 자간 -0.025em.
- 구획 제목: 28~32픽셀. 제목 위보다 아래 간격을 짧게 둡니다.
- 보조 안내: 13~14픽셀. 설치 위험과 지원 환경을 과도하게 작게 표시하지 않습니다.
- 버전·PID·명령어: SFMono-Regular 계열. 명령어와 실제 데이터에만 사용합니다.

로고 C의 한글 글자는 서체를 바탕으로 한 시안입니다. 폰트 파일 포함이나 윤곽선 변환 여부는 logos/NOTES.md에 기록하며, 최종 상표용 원본과 구분합니다.

## 로고 사용

- A: 상태 표시를 중심으로 한 심벌.
- B: 유지·되돌림을 중심으로 한 지킴이 심벌.
- C: 한글 이름을 중심으로 한 워드마크.

A안을 기본 로고로 사용하며, B·C는 검토 기록으로 보존합니다. A안 기본형은 흑연색 화면 윤곽과 중앙 초록 점이며, 어두운 바탕에서는 밝은 윤곽과 초록 점을 사용합니다. 단색 인쇄용도 별도로 제공합니다. 로고의 점은 고정 브랜드 표식이며 실제 작동 상태는 별도 UI로 표시합니다.

최소 여백은 심벌 높이의 1/4, 심벌 기준 크기는 16·24·32픽셀입니다. 워드마크를 16픽셀 안에 억지로 넣지 않습니다. 16픽셀용 심벌은 실제 픽셀 렌더를 검수한 뒤 확정합니다.

## 제품 이미지와 앱 화면

기존 Mac 이미지는 유지 가능한 자산입니다. 다만 이미지 안에 포함된 청록 반사광은 배경색만 바꿔도 남으므로, 후속 페이지 적용에서 중립 배경과 어울리는지 확인해야 합니다. 합성 이미지를 실제 앱 화면으로 표현하지 않습니다.

앱 미리보기는 수평으로 배치하고 과도한 기울기·광택·큰 부유 그림자를 줄입니다. 사용자에게 없는 기능이나 가짜 성능 수치를 넣지 않습니다. 현재 페이지의 스크롤 연출은 이 단계에서 변경하지 않습니다.

## 페이지 적용 기준

- 주요 설명, 다운로드, 지원 환경이 첫 화면에서 연결되도록 합니다.
- 로고 선택 후 기존 index.html·styles.css에 필요한 변경만 적용합니다.
- 다운로드 URL, 버전, 설치 경고, 기능 설명과 실제 토글 접근성을 보존합니다.
- 제품 영역의 거대한 장식 영문과 반복적인 색상 강조를 줄입니다.
- 랜딩페이지의 숫자 순서는 실제 설치·복원 순서를 설명할 때만 사용합니다.
- 모바일에서는 읽기 순서를 유지하고 가로 스크롤이 생기지 않도록 합니다.
- 모션은 사용자 동작에 대한 반응에 한정하며 reduced-motion 설정을 존중합니다.

## 이번 단계의 확정 범위

BI·VI 문서와 비교 보드는 사용자 검토용 초안입니다. 선택한 A안을 website/에 적용하며 네이티브 앱 아이콘은 변경하지 않습니다. 새 브라우저 저장소·외부 폰트·분석 코드·자동 디자인 훅을 추가하지 않습니다.


## 로고 선택 확정

2026-11-03 사용자가 A안을 선택했습니다. 첨부한 Mac 메뉴 막대 아이콘의 화면 윤곽과 상태점을 브랜드 연속성의 근거로 삼습니다. 웹사이트에는 화면 윤곽·중앙 초록 점·하단 받침선으로 구성한 수정 A안을 사용합니다. 로고의 중앙 초록 점은 브랜드 표식이며 실제 앱의 현재 상태를 뜻하지 않습니다. 기존 네이티브 앱 아이콘은 변경하지 않습니다.


## 사용자 참조 아이콘 반영

추가 메뉴 줄·우측 점·화면 내부 가로선을 제거했습니다. 첨부한 Mac 메뉴 막대 아이콘과 기존 menuIcon의 22×20 비례를 바탕으로 화면 윤곽 하나, 중앙 점 하나, 하단 받침선 하나만 사용합니다. 밝은 바탕의 초록 점은 #237A4B, 어두운 바탕은 #30D158입니다. Mac 앱 소스와 아이콘은 변경하지 않습니다.
