# 원격지킴이 리브랜딩 검토

검토일: 2026-11-03
방식: 독립 에이전트 2개. A는 디자인 판단, B는 기계 탐지와 계산 스타일을 담당했습니다. A의 판단이 끝난 뒤 B의 결과를 종합했습니다.

## 결론

콘텐츠와 구조를 전부 교체하기보다 색의 역할부터 분리하는 방향이 적합합니다. 제품 이미지, Mac 사용 환경, 켜기·복원 설명은 유지할 근거가 있습니다. 반면 청록 제목·청록 무대·민트 라벨·녹색 아이콘의 반복은 작은 Mac 도구보다 일반적인 AI 서비스의 인상을 앞세웁니다.

BI는 '필요한 동안 깨어 있게, 마치면 이전 설정으로'로 정리했습니다. VI는 중립 실버와 흑연을 기본으로 하고 초록을 실제 작동 상태에만 사용하도록 제안합니다. 브랜드명은 원격지킴이, 보조 영문명은 RemoteLid로 통일합니다.

## 유지할 요소

- 제품 효용과 다운로드·지원 환경이 연결된 첫 화면의 정보 구조.
- MacBook·데스크톱 Mac 이미지와 메뉴 막대 도구라는 사용 환경.
- 설정 복원·배터리 경고·관리자 인증과 공증 미적용을 설명하는 제품 사실.

## 기계 탐지의 해석

CLI 원본은 [detector.json](detector.json)에 있습니다. 30건은 대비 경고 8건, 작은 UI 글자 8건, 작은 글자 8건, 여백 4건, 제목 위 작은 라벨 1건, 배경 발광 1건입니다. 중복과 장식 요소가 있으므로 30개의 독립된 결함을 뜻하지 않습니다.

B의 브라우저 계산 스타일로 확인한 기본 본문 대비는 4.764:1로 통과했습니다. 미리보기 보조 설명 3.020:1, 설정 설명 3.452:1, 미리보기 표식 3.107:1, 안전 제한 안내 4.039:1은 일반 본문 기준에 부족했습니다. 장식용 STAY AWAKE 글자는 본문 실패로 합산하지 않았습니다. 여백 경고 4건은 실제 패딩·개별 배치와 대조하여 오탐 가능성을 구분했습니다.

## 로고 방향

A는 상태 표시로 기존 앱과의 연결이 빠릅니다. B는 유지와 복원을 추상적인 형태로 표현합니다. C는 한글 이름을 읽는 데 초점을 둡니다. 원안과 단색·반전을 비교한 뒤 선택해야 하며 16픽셀에서는 세부 묘사의 생존보다 실루엣과 상태 혼동 여부를 확인해야 합니다.

이 단계에서는 로고의 색상·형태와 페이지 적용 기준을 제안했습니다. 상표 조사, 최종 글자 윤곽선 마감, 네이티브 앱 아이콘 교체는 수행하지 않았습니다.

## 실행 근거와 한계

- A: ego-browser 독립 작업 공간 24에서 실제 화면 확인 후 종료했습니다. 휴리스틱 점수는 25/36이며 앱 실행 품질 점수가 아닙니다.
- B: 작업 공간 25에서 페이지 구조와 계산 스타일을 확인했습니다. 임시 title/script 변경으로 주입 가능성까지 확인했지만, 사용자 제어로 전환되어 detector overlay 주입이 중단됐습니다. 오버레이 실행·그림·콘솔 검출 결과는 확인하지 못했습니다.
- B가 시작한 detector 서버 PID 74072, 포트 8400은 종료했습니다. 사용자 제어 작업 공간은 임의로 회수하거나 종료하지 않았습니다. 해당 탭의 임시 제목·스크립트는 새로고침하면 사라집니다.
- `.impeccable/critique/ignore.md`는 없었습니다. A와 B의 상세 근거는 [review-A.md](review-A.md), [review-B.md](review-B.md)에 있습니다.
- 모바일 기존 페이지 실기기, VoiceOver 전체 흐름과 실제 설치 스크립트 실행은 검증하지 않았습니다.
