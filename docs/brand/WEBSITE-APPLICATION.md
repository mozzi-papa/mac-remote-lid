# A안 웹 적용 기록

적용일: 2026-11-03

## 선택과 적용

사용자가 A안을 선택하고 현재 Mac 메뉴 막대 아이콘의 화면 윤곽과 상태점 이미지를 참고 자료로 제공했습니다. 기존 앱과의 연결성을 유지하도록 A안의 단색 웹 로고를 `website/icon.svg`에 적용했습니다. 네이티브 앱 아이콘은 변경하지 않았습니다.

- 페이지 기본 배경·본문·보조 글자·구분선을 VI의 실버·흑연색 토큰으로 정리했습니다.
- 청록·민트 제목 강조, 배경 조명, 설치 패널 테마 색상을 중립색으로 교체했습니다.
- 초록은 데모의 켜짐 상태와 스위치에 사용합니다. Mac 창의 닫기·최소화·확대 표시색은 유지합니다.
- 기존 하드웨어 이미지 파일은 수정하지 않고 CSS grayscale로 중립 톤을 표시합니다.
- 제목의 과도한 자간을 줄이고 작은 보조 안내의 크기와 대비를 보완했습니다.
- 반복되는 제목 위 장식 문구를 줄이고 거대한 배경 영문을 숨겼습니다. 기존 데모와 스크롤 연출에 필요한 요소는 유지했습니다.
- 영문 보조 브랜드를 RemoteLid로 통일했습니다.
- 설치 설명은 자동 설치 방식과 서명·공증 안내를 함께 읽도록 정리했습니다.

## 검증

- 기존 DOM ID 전체와 외부 링크 목록이 유지되는지 변경 전 소스와 비교했습니다.
- 중복 ID, 내부 앵커, 로컬 이미지·스크립트·CSS 참조와 SVG XML을 검사했습니다.
- 웹 로고와 선택된 A안 원본의 일치를 확인했습니다.
- `node --check website/app.js`, `git diff --check`를 통과했습니다. app.js는 변경하지 않았습니다.
- 로컬 페이지를 ego-browser에서 한 번 열었습니다. 콘솔 오류·실행 예외와 실패 요청이 없었습니다.
- 변경 후 Impeccable 탐지 결과는 `detector-after.json`입니다. 기존 30건에서 여백 경고 4건만 남았습니다. product-stage의 절대 위치 배치, window-bar의 수직 정렬, safety-section의 내부 wrap, faq-section의 구획 패딩과 관련된 경고입니다. 이 경고가 실제 렌더 결함이 아니라는 최종 판정까지 하지는 않았습니다.
- 검증용 서버 PID 16950, 포트 64547과 브라우저 작업 공간 28은 검증 후 종료했습니다.

## 미실시

사용자의 브라우저 검증 단계 규칙에 따라 이번 랜딩페이지 수정은 콘솔 확인까지만 진행했습니다. 클릭·스크린샷·모바일 흐름 등 상세 브라우저 테스트는 수행하지 않았습니다. Git 커밋·push·GitHub Pages 배포, 네이티브 앱 아이콘 교체와 상표 조사는 수행하지 않았습니다.
