# 원격지킴이 로고 3안 제작 요청

## 승인과 작업 범위

사용자가 로고 3안 제작과 agy --dangerously-skip-permissions 실행을 승인했습니다. 다른 에이전트가 같은 저장소에서 작업 중입니다. 파일 생성·수정은 docs/brand/logos/ 안으로 제한하고 다른 작업자의 변경을 되돌리지 마세요. Source/, website/, 기존 스킬은 수정하지 마세요. Git 상태 변경 명령과 AWS CLI는 실행하지 마세요. 새로운 영속 저장 기술을 도입하거나 기존 저장 기술을 변경하지 마세요. 사용자 대화는 한국어 반말, 문서·코드 주석은 한국어 존댓말로 작성하고 한자 문자·과장·아부는 사용하지 마세요. 모델을 임의로 바꾸지 마세요.

## 브랜드

브랜드명: 원격지킴이. 보조 영문명: RemoteLid.
Apple Silicon Mac의 잠자기를 방지하고, 끄면 변경 전 전원 설정으로 복원하는 작은 메뉴 막대 앱입니다. 원격 접속 자체나 보안을 제공하는 앱이 아닙니다. 화면 꺼짐 방해 앱을 조회하는 기능도 있습니다.
핵심 약속: 필요한 동안 깨어 있게, 마치면 이전 설정으로.
성격: 조용함, 명확함, 통제 가능함. Mac 하드웨어와 시스템 UI에 어울리는 실용적인 도구.
시각 방향: 알루미늄 실버, 중립 회색, 흑연색. 초록은 작동 상태 표시를 위한 색입니다. 청록·민트 배경, 네온, 보라 그라데이션, 유리 질감, 과한 입체 효과, AI 반짝이 장식은 사용하지 마세요.
기존 자료: website/icon.svg, website/index.html, website/styles.css. 읽기만 가능합니다.

## 서로 다른 3안

A: Mac 상태 표시 중심. 화면 또는 메뉴 막대와 작은 상태 표시의 관계로 '작업 유지'를 표현합니다.
B: 지킴이 심벌 중심. 유지·되돌림을 표현하는 단순한 연결 또는 받침 형태를 탐색합니다. 방패·자물쇠로 보안 기능을 암시하지 마세요.
C: 한글 워드마크 중심. '원격지킴이'의 읽기 쉬운 이름과 작은 보조 심벌로 구성합니다. 한글을 정확하게 표기해 주세요.

## 산출물

로고는 3개만 제안하고 각 안이 단순한 색상 변형이 아니라 다른 형태를 갖도록 해 주세요.
각 안의 logo-a.svg / logo-b.svg / logo-c.svg와 NOTES.md를 작성해 주세요. 직접 벡터로 제작하거나 사용 가능한 디자인·이미지 도구를 활용할 수 있습니다. 이미지 생성 결과를 사용한다면 원본을 함께 보존하고, 일치하지 않는 벡터를 원본이라고 표기하지 마세요.
SVG는 외부 의존성·스크립트·외부 이미지 없이 만들고, viewBox를 포함해 주세요. 워드마크에 시스템 글꼴을 사용했다면 NOTES.md에 명시하고 최종 윤곽선 로고로 오해하게 하지 마세요.

NOTES.md에는 각 안의 의도, 작은 크기에서의 제한, 추천안과 이유를 기록해 주세요. 최종 로고는 사용자가 선택하므로 website/에 적용하지 마세요.
