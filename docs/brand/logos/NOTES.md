# 원격지킴이 (RemoteLid) 로고 3안 제작 및 검수 노트

## 1. 브랜드 시각 정체성(BI/VI) 정렬 기준

`docs/brand/BRIEF.md`와 `docs/brand/DESIGN.md`의 기준에 따라 로고 체계를 다음과 같이 정리했습니다.

- **기본 색상과 작동 상태색의 분리**:
  - B·C의 탐색 시안은 단색 기준이며, 최종 선택한 A안은 사용자 요청대로 중앙 초록 점을 포함합니다.
  - 어두운 배경에서는 **밝은 단색 반전 Canvas(`#FCFCFD`)** 버전을 사용합니다.
  - A안 중앙 초록 점은 고정 브랜드 표식입니다. 실제 작동 여부는 별도 UI의 상태 표시로 안내합니다.
- **초기 상태점 포함 원안의 보존**:
  - 초기 탐색 단계에서 초록 작동 상태점을 로고 내부에 포함해 제작했던 `logo-b.svg`, `logo-c.svg` 및 C안 보조 심벌 원안 `logo-c-symbol.svg`는 참고 시안으로 그대로 보존했습니다.
- **기술 및 형태 원칙**:
  - 청록·민트 배경, 네온, 보라 그라데이션, 장식용 유리 효과, 방패·자물쇠 등 보안·원격 접속 기능으로 오해할 수 있는 요소를 사용하지 않았습니다.
  - 모든 SVG 파일은 `viewBox`를 포함하며 외부 폰트, 외부 이미지, 스크립트 의존성이 없는 순수 벡터입니다.

## 3. 각 안의 의도와 작은 크기(16·24·32px)에서의 제한

최소 여백은 심벌 높이의 1/4이며, 심벌 기준 크기는 `16px`, `24px`, `32px`입니다. **모든 소형 심벌(특히 16픽셀)은 실제 픽셀 렌더를 검수하기 전까지 선명성을 단정하지 않으며**, 각 구조가 지닌 물리적 제한은 다음과 같습니다.

### A안 — 사용자 참조에 맞춘 수정본

- 사용자 요청에 따라 상단 메뉴 줄·추가 점·화면 내부 가로선을 제거했습니다.
- 기존 Mac 메뉴 막대 아이콘의 22×20 비례를 따릅니다. 화면 윤곽 1개, 중앙 점 1개, 하단 받침선 1개로 구성합니다.
- 웹 기본형은 logo-a.svg: 흑연색 윤곽과 초록 중앙 점입니다. logo-a-reverse.svg는 밝은 윤곽과 초록 점입니다. logo-a-mono.svg는 단색 인쇄용 보조 파일입니다.
- 로고의 초록 점은 고정 브랜드 표식이며 실제 앱 작동 여부를 뜻하지 않습니다.
- 작은 크기에서는 세부 장식 대신 실루엣과 중앙 점을 유지합니다. 실제 Mac 메뉴 막대의 색·렌더링까지 완전히 동일하다고 보장하지는 않습니다.

### B안 (`logo-b-mono.svg` / `logo-b-reverse.svg` / `logo-b.svg`) — 지킴이 심벌 중심
- **제작 의도**:
  - 방패나 자물쇠 같은 보안 상징을 배제하고, 하단 받침 브래킷(깨어 있는 상태 유지)과 상단 복귀 화살표 호(끄면 이전 전원 설정으로 복원), 좌상단 기준점·우하단 유지점을 결합해 '유지와 되돌림'의 약속을 표현합니다.
- **작은 크기에서의 제한**:
  - 상단 복귀 화살촉(`M26.5 6L20 11L26.5 16`)과 좌상단 기준점(`cx="16" cy="23"`), 그리고 중앙 수평선(`M25 32H39`)이 좁은 간격으로 마주하고 있습니다.
  - `16px` 환경에서는 화살촉 안쪽 각도와 인접한 원형 점 사이의 여백이 1픽셀 미만으로 좁아져 안티앨리어싱 번짐이 발생할 수 있으므로, 실제 픽셀 렌더를 확인한 뒤 화살촉 크기나 점 간격을 조정해야 합니다.

### C안 (`logo-c-mono.svg` / `logo-c-reverse.svg` / `logo-c.svg` 및 `logo-c-symbol-*.svg`) — 한글 워드마크 중심
- **제작 의도**:
  - 읽기 쉬운 `'원격지킴이'` 한글 워드마크와 보조 영문 `'REMOTELID'`를 중심으로 하고, 좌측에 이전 설정 기준점과 유지 노브를 담은 작은 토글 심벌을 배치했습니다.
  - 정사각형 아이콘 영역에서 워드마크를 억지로 축소하지 않도록 좌측 보조 심벌을 `logo-c-symbol-mono.svg`, `logo-c-symbol-reverse.svg`, `logo-c-symbol.svg`로 별도 분리했습니다.
- **시스템 글꼴 시안 안내 (중요)**:
  - `logo-c-mono.svg`, `logo-c-reverse.svg`, `logo-c.svg`의 한글과 영문 텍스트는 로컬 시스템 산세리프(`Apple SD Gothic Neo`, 시스템 sans-serif) 및 모노스페이스(`SFMono-Regular`) `<text>` 요소를 사용한 시안입니다.
  - **폰트 파일이 내장되어 있지 않으며 최종 상표용 윤곽선(Outlined Path) 원본이 아닙니다.** 최종 로고로 선택할 경우 글자를 윤곽선(`<path>`)으로 변환하고 자간을 고정하는 마감 작업이 필요합니다.
- **작은 크기에서의 제한**:
  - 가로형 워드마크(`320×72`)는 `16px`·`24px`·`32px` 심벌 영역에 사용할 수 없으며 반드시 분리된 보조 심벌(`logo-c-symbol-*.svg`)을 사용해야 합니다.
  - 분리된 보조 심벌 또한 바깥 둥근 사각 테두리와 안쪽 토글 캡슐 트랙의 이중 선 구조로 되어 있어, `16px`에서는 두 선 사이 여백과 내부 작은 기준점(`r="3"`)이 좁아지는 제한이 있습니다. 실제 픽셀 렌더 검수 시 16픽셀에서는 바깥 사각 테두리를 생략하고 토글 캡슐만 남기는 조정을 검토해야 합니다.

## 4. 최종 선택과 사용 기준

사용자가 A안을 선택한 뒤 실제 Mac 메뉴 막대 아이콘을 참조로 제공했습니다. 수정 A안은 해당 형태에 맞췄으며 웹 기본형은 logo-a.svg입니다. 단색 인쇄용은 logo-a-mono.svg, 어두운 배경은 logo-a-reverse.svg를 사용합니다. 한글 이름은 기존 시스템 서체로 병기합니다. B·C는 검토 기록이며 네이티브 앱 아이콘은 수정하지 않았습니다.
