# 원격지킴이 디자인 검토 A

검토일: 2026-11-03  
대상: `website/index.html`, `website/styles.css`, `website/app.js`, [공개 페이지](https://mozzi-papa.github.io/mac-remote-lid/)  
방식: 독립 디자인 검토. Assessment B 및 detector 결과를 보지 않고 판단하였습니다.  
모드: Persuade. 제품은 macOS 전원 설정 도구이며 원격 접속이나 보안 서비스를 제공하지 않습니다.

## 판단

현재 페이지는 콘텐츠와 Mac 제품 렌더에서 제품 특수성이 보이지만, 색상 체계는 다른 AI 또는 SaaS 제품에도 그대로 옮길 수 있는 모습입니다. 청록 제목, 청록빛 네이비 무대, 민트 라벨, 녹색 아이콘이 화면 전반에 반복되어 사용자가 말한 “AI스럽다”는 인상을 만듭니다. 색 하나보다 서로 겹치는 색의 역할이 원인입니다.

구조를 다시 만들 필요는 없습니다. 실버와 흑연을 기본으로 두고 초록을 실제 활성 상태에만 사용하면 Mac 유틸리티라는 성격을 더 정확히 전달할 수 있습니다. 이번 단계는 브랜드 선택을 위한 검토이며 웹이나 앱 구현 변경을 제안 범위에 포함하지 않습니다.

## 유지할 장점

- **핵심 효용이 빠르게 읽힙니다.** “Mac은 켜두고. 작업은 계속.”과 다운로드 버튼이 첫 화면의 중심을 이룹니다. Apple Silicon, macOS 버전, 공증 여부도 다운로드 가까이에 있습니다.
- **Mac이라는 사용 환경이 구체적입니다.** MacBook과 데스크톱 Mac 렌더, 메뉴 막대 앱 미리보기, 켜짐과 복원 상태가 일반적인 서비스 소개와 구분됩니다.
- **신뢰의 근거가 실제 동작에 있습니다.** 이전 설정 기록과 복원, 배터리 경고, 인증 주체, 미리보기 한계를 설명합니다. 과도한 보안 보증보다 이 설명을 브랜드의 근거로 유지하는 편이 적합합니다.

## 우선 문제

| 우선순위 | 문제와 근거 | BI·VI 반영 방향 |
|---|---|---|
| P1 | **초록이 상태와 장식을 동시에 맡습니다.** `--teal`이 제목, 보조 제목, 단계 번호, 기능 아이콘, 링크에 쓰이고 민트가 무대 라벨과 설치 안내에 반복됩니다. 켜짐 상태의 초록과 브랜드 장식의 초록이 구분되지 않습니다. | 제목·기능 아이콘·일반 링크는 흑연과 중립 회색으로 통일하고, 초록은 켜짐 점과 스위치 등 상태 요소에만 배정합니다. |
| P2 | **배경 전체가 청록 기운을 강화합니다.** 밝은 종이색에도 푸른 기운이 있고, 무대의 방사형 그라데이션과 실버 하드웨어 가장자리에도 청록빛이 보입니다. 텍스트만 무채색으로 바꾸면 기존 인상이 남습니다. | 배경·무대·렌더의 색온도를 함께 정리합니다. 중립 실버 바탕과 흑연 무대로 소재 대비를 만들고, 빛 효과를 새로 늘리지 않습니다. |
| P2 | **브랜드의 작은 표식이 일반적인 원격 화면 아이콘에 가깝습니다.** 현재 아이콘은 노트북 윤곽과 점으로 읽혀 원격 접속 도구로도 해석될 수 있습니다. 페이지의 “원격 모드”라는 표현도 같은 방향을 보강합니다. | 로고는 Mac의 깨어 있음과 설정의 되돌림 중 한 가지를 간결하게 표현합니다. 방패·자물쇠·연결망을 브랜드 중심 상징으로 쓰지 않습니다. 원격 기능을 새로 제공한다는 인상을 피합니다. |
| P2 | **색 외의 장식도 제품보다 앞설 수 있습니다.** 큰 영문 `STAY AWAKE.`, 기울어진 미리보기, 긴 스크롤 무대가 동시에 사용됩니다. 멋을 유지하되 유틸리티의 정확함을 가리는 요소가 됩니다. | 현재 구성은 유지하고 영문 배경 글자의 존재감과 미리보기 회전을 약하게 조정하는 정도로 제한합니다. 색상 선택 단계에서 구조 교체로 확대하지 않습니다. |
| P2 | **신뢰 설명의 강도가 고르지 않습니다.** 설치 카드의 “보안 경고 없이”는 아래 공증 미적용 안내보다 강한 문구입니다. 전원 설정을 직접 바꾸는 앱의 신뢰는 색이나 로고만으로 해결되지 않습니다. | BI에서 “확인 가능한 동작, 사용자가 이해한 실행”을 문구 원칙으로 둡니다. 설치 문구 수정은 별도 승인 대상으로 남기고, 이번에는 브랜드가 보안을 보증하는 표현을 만들지 않습니다. |

P0에 해당하는 사용 불가 문제는 이 시각 검토에서 발견하지 않았습니다. P1은 핵심 리브랜딩 요구와 직접 충돌하는 색의 역할 문제를 뜻합니다.

점수는 0~4이며 높을수록 좋습니다. 설치 안내를 포함한 랜딩페이지 기준으로 평가했습니다. 실제 macOS 앱 동작의 품질 점수가 아닙니다.

## 인지 부담과 감정 흐름

인지 부담 체크리스트에서는 묶음, 시각 위계, 한 번에 한 결정, 선택 수, 기억 부담, 점진적 공개가 대체로 충족됩니다. 작은 설명과 장식의 겹침으로 **청킹 항목 1개를 부분 실패**로 보아 부담은 낮은 편으로 평가합니다. 다섯 개 기능 항목은 정보 목록이며 다섯 개 동시 행동 선택지는 아닙니다. 주 다운로드와 설치 안내, 상단 메뉴 세 개는 서로 묶여 있어 한 결정 지점의 행동이 네 개를 넘는 문제는 두드러지지 않습니다.

첫 화면은 작업을 이어갈 수 있다는 안도감을 줍니다. 큰 하드웨어 무대가 시각적 정점을 만들고, 설치 구역의 관리자 인증과 공증 미적용 설명에서 부담이 커집니다. 마지막 다운로드로 돌아올 때 신뢰를 더하려면 새 보증 문구보다 실제 설정 복원과 제품 한계를 차분하게 보여주는 것이 적합합니다.

## 사용자 관점의 경고

- **처음 쓰는 사용자:** “원격 모드”와 제품명 때문에 원격 접속 자체를 제공한다고 기대할 수 있습니다. “전원 설정 도구”라는 제품 설명을 BI의 기본 정의로 고정하는 편이 좋습니다.
- **조건을 꼼꼼히 읽는 사용자:** “보안 경고 없이”와 공증 미적용 안내의 강도가 달라 판단이 늦어질 수 있습니다. 이번 브랜드 작업에서는 안전을 시각적으로 과장하지 않아야 합니다.
- **모바일에서 살펴보는 사용자:** 390px 첫 화면에서 핵심 문구와 다운로드는 읽히지만 기기·버전·공증 안내는 작습니다. 브랜드 비교 보드에서도 작은 크기 사용 예시를 포함해야 합니다. 모바일에서 Mac 앱을 설치하는 흐름 자체는 검증하지 않았습니다.

## BI·VI 문서 반영 제안

**브랜드 정의:** “Mac의 잠자기를 관리하고, 사용을 마치면 앱이 바꾼 설정을 되돌리는 작은 메뉴 막대 도구”를 기준으로 삼습니다. 연결·감시·보안 보증보다 지속과 복원에 의미를 둡니다.

**색의 역할:** 실버는 바탕과 소재, 흑연은 제목·아이콘·주 행동, 중립 회색은 보조 설명과 구분선에 사용합니다. 초록은 켜짐 상태에만 사용하고, 꺼짐은 중립 회색, 주의는 필요한 위치의 제한된 황색으로 분리합니다. 정확한 색상값은 후보 보드에서 결정하고 이번 검토에서 새 팔레트를 확정하지 않습니다.

**로고 비교 기준:** 세 안은 동일 크기·동일 배경에서 비교하고, 흑백 단색·메뉴 막대 작은 크기·앱 아이콘·웹 헤더를 함께 보여줍니다. 서로 다른 배경 효과로 후보의 완성도를 다르게 보이게 하지 않습니다. 기기 윤곽, 깨어 있음, 되돌림 중 핵심 의미를 한 가지씩 다르게 잡는 편이 구별하기 쉽습니다.

**타이포그래피와 구성:** macOS 시스템 서체와 현재 한글 문구 위계를 유지합니다. 새 장식 서체나 배지를 추가하지 않습니다. 기존 하드웨어 렌더는 중립 색온도에 맞춰 활용할 수 있지만 Apple 공식 제품이라는 인상을 만드는 문구나 표식은 추가하지 않습니다.

## 선택 단계의 질문

1. 작은 메뉴 막대에서 노트북 윤곽보다 “깨어 있음”이 먼저 읽혀야 합니까, “원래대로 복원”이 먼저 읽혀야 합니까?
2. 전체가 실버와 흑연일 때도 초록 점 하나로 켜짐 상태가 충분히 보입니까?
3. 로고에서 원격 접속이나 보안을 연상시키는 요소를 덜어도 제품명을 기억할 수 있습니까?

질문은 부모 검토에서 로고 비교와 함께 제시하도록 남겼습니다. 이 독립 검토에서 사용자에게 별도 응답을 요청하지 않았습니다.

## 확인 범위

공개 페이지의 데스크톱 첫 화면·제품 무대·설치 구역과 390px 첫 화면을 ego-browser에서 시각 확인하였습니다. 독립 taskspace 24는 `finish({ keep: [] })`로 종료하였습니다. detector 결과는 읽지 않았으며 네이티브 앱·다운로드 실행·키보드 전체 흐름·정량 대비율은 검증하지 않았습니다.

수정 파일은 이 문서뿐입니다. 웹 적용과 Source/main.swift 변경은 수행하지 않았습니다. 이 검토만으로 접근성 준수나 설치 안전성을 보증할 수 없습니다.
